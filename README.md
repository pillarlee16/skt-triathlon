# SKT 철인3종 럭키드로우

Vite, TypeScript, Three.js와 Vercel Functions를 사용하는 행사 운영 웹앱입니다. 본행사 추첨과 에셋은 Vercel Private Blob에 저장합니다. 개발 인수인계는 [PROGRESS.md](PROGRESS.md)를 확인하세요.

## 로컬 리허설

Node.js 24에서 아래 명령을 실행한 뒤 Vite가 표시한 주소의 `/admin?mode=rehearsal`을 여세요. 로컬 비밀번호는 `rehearsal`입니다. 로컬 리허설 데이터는 프로세스가 종료되면 초기화됩니다.

```sh
npm install
npm test
npm run typecheck
npm run build
npm run dev
```

## Vercel 배포

1. 승인된 Vercel 프로젝트에 이 폴더를 연결합니다. Framework Preset은 Vite, Node.js는 24.x, 빌드 명령은 `npm run build`, 출력 디렉터리는 `dist`입니다.
2. Production과 Preview 각각에 Private Blob 스토어를 연결해 환경별 `BLOB_READ_WRITE_TOKEN`을 제공합니다. 운영 비밀번호 `ADMIN_PASSWORD`와 32자 이상 무작위 값 `SESSION_SECRET`을 환경별로 설정합니다. 미리보기에는 가상 참가자만 사용합니다.
3. Preview에서 전체 리허설을 진행합니다. 본행사 데이터의 Vercel 사용에 대한 사내 승인을 확인한 뒤 Production에만 `APP_LIVE_ENABLED=true`를 설정하고 재배포합니다.
4. 운영 URL을 관리자와 태블릿에서 열어 로그인과 START 연동을 확인합니다. 배포 자체에 Vercel 접근 제한을 적용한 환경이라면 태블릿에서 해당 배포에 접근할 수 있게 설정합니다.

## 행사 운영과 복구

1. `/admin?mode=live`의 참가자·상품에서 Excel 템플릿을 받습니다. 가상 예시를 실제 값으로 교체합니다. 앞자리에 0이 있는 참가번호는 Excel에서 텍스트로 입력합니다. 사진과 상품 이미지 파일명은 에셋에 올릴 파일과 맞춥니다. 이미지는 JPG·PNG·WebP, 음원은 MP3·WAV·OGG를 지원하며 업로드 한도는 변환 후 파일당 4 MB입니다.
2. 에셋·방송 설정에서 사진과 상품 이미지, 로고, 사장님 얼굴, 사운드를 등록합니다. 관리자와 송출을 같은 브라우저 프로필에서 열고 송출 창에서 음향 켜기와 전체 화면을 누릅니다. 행사 노트북의 화면 복제 설정으로 TV 두 대에 같은 영상을 송출합니다.
3. 경기 진행에서 수영을 준비하고 관리자 화면의 START를 누릅니다. 태블릿으로 시작하는 경우 태블릿을 활성화하고 링크를 엽니다. 링크는 현재 준비된 경기에서 30분 동안 유효합니다. 결승 후 **시상식 시작**을 누릅니다. 3위·2위·1위 공개가 끝나도 시상 화면은 유지됩니다. 사회자의 호명·촬영 완료 큐를 받고 다음 종목 준비 화면 또는 철인3종 종료로 넘어갑니다.
4. 브라우저나 노트북을 다시 시작하면 같은 운영 URL에 로그인합니다. 진행 중인 경기와 이미 저장된 결과가 서버에서 복구됩니다. TV 창을 다시 열면 **음향 켜기**를 누르고, 운영 콘솔의 TV 연결·음향 상태를 확인합니다. 3D 장치 문제가 있으면 HTML 대체 화면으로 경주와 시상을 계속할 수 있습니다. 비상 발표는 준비, 카운트다운, 경주, 결승 단계에서 사용할 수 있으며 이미 추첨했다면 저장된 순위를 사용합니다. 연결이 지연되면 처리 상태와 현재 단계를 확인하고, 콘솔에 **같은 요청 재시도**가 표시될 때 해당 버튼을 사용합니다.
5. 이전 결과를 정정할 때 결과·이력에서 종목을 선택해 사유를 입력합니다. 선택한 종목과 그 이후의 결과가 무효화되며, 해당 종목 준비 화면에서 다시 시작합니다. 공식 결과 CSV에는 현재 유효한 결과만 들어갑니다.
6. 행사 종료 후 CSV를 보관하고, 승인된 보관 기준에 따라 Vercel 운영 스토어의 상태와 업로드 에셋을 정리합니다.

사진 파일명을 비워 두면 참가번호와 같은 파일명으로 얼굴을 찾습니다. 예를 들어 참가번호 `01`은 `01.jpg`로 연결할 수 있습니다. 의상을 지정하려면 참가자 시트에 선택 열 `의상 색상`을 추가하고 `#RRGGBB` 형식으로 입력합니다.

신규 세션 기본 경주 시간은 종목별 40초입니다. 기존 세션의 저장된 설정은 유지되므로, 행사 전 승인된 운영 환경의 **에셋·방송 설정**에서 세 시간 값을 확인하세요. 경주 시간에는 출발 대기, 카운트다운, 시상이 포함되지 않습니다.

## 네트워크 장애 시 운영

- Vercel 배포본은 브라우저에서 Vercel에 접속해야 하며, 서버는 Private Blob에 상태 및 에셋을 저장합니다. 행사 노트북에서 승인된 예비 네트워크로 같은 운영 URL에 재접속하고, 관리자 단계와 TV·음향 상태를 확인합니다.
- 가상 명단 로컬 리허설은 의존성을 미리 준비하면 인터넷 없이 같은 노트북에서 실행할 수 있습니다. `npm run dev`로 서버를 켜고 `http://127.0.0.1:5173/admin?mode=rehearsal`과 TV 송출 창을 같은 브라우저 프로필에서 엽니다. 서버를 종료하면 리허설 상태가 사라지며, 현재 로컬 모드는 Vercel 운영 상태를 읽거나 복구할 수 없습니다.
- 공식 추첨 중 연결이 끊기면 사회자가 진행을 잠시 보류하고, 운영자는 같은 운영 세션으로 재접속합니다. 이미 확정된 당첨자와 발표 단계를 확인하고 재개합니다. 같은 세션에 접속할 수 없으면 행사 책임자가 사전에 승인한 백업 절차를 적용합니다. 이미 추첨한 종목은 승인된 결과 사본으로만 이어가고, 당첨자가 확인될 때까지 해당 종목의 재추첨이나 이후 종목 추첨을 보류합니다. 로컬 가상 리허설은 송출 점검용으로 사용합니다.

## 현장 리허설

- 90명 얼굴 로딩과 선두 얼굴 식별, 1080p 두 TV 동일 송출과 30fps 목표를 확인합니다.
- 관리자·태블릿 동시 START, 경기 중 새로고침, 네트워크 재연결, 3D 장애 시 비상 발표를 확인합니다.
- 수영 → 사이클 → 달리기를 끝까지 진행해 9명 중복 여부, 결승·발표·CSV 일치, 재추첨 영향 범위를 확인합니다.
